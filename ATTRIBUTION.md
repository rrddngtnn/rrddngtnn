Statistics use the standard [GitHub Readme Stats Action](https://github.com/stats-organization/github-readme-stats-action) v2, pinned at `2c498845f71017821efaad14293ebc736156ef21`, with maintained upstream core `2.3.0` (MIT). The original GitHub Readme Stats repository now directs users to this maintained action. Only color options match the ice palette; layouts and metrics are upstream defaults, with `show_icons=true` and `layout=compact&langs_count=6`.

The public `github-readme-stats.vercel.app` stats and top-languages endpoints returned HTTP 503 `DEPLOYMENT_PAUSED` during setup. Instead, authenticated GitHub Actions generates the same conventional card types as static SVGs, not a hand-designed fallback. `GITHUB_TOKEN` supplies public statistics; private data is not requested. The default commit metric is year-to-date, not lifetime commits. Language percentages describe upstream repository code-byte usage, not personal skill or contributions to others' repositories; upstream repository/query limits apply. API errors fail the job before publication.

The Streak section uses [DenverCoder1/github-readme-streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats), pinned at `125aaaf200620410446ebfa51897fca3607e04fd` (MIT). All four SVGs are produced by unmodified upstream entry points from authenticated live data and committed locally in the profile repository. Streak's public service was working, but local generation avoids dependence on its availability. No profile-view count is claimed: page visits are not unique profile visitors, and no existing verified counter was supplied. No Activity Graph or custom card renderer is used.

A prior workflow failed before creating any jobs: GitHub's run page reported `Internal server error` with correlation ID `107ad576-27e7-4ef8-8ee4-b1c4506b1ec4`. The new pipeline avoids nested stats composite expansion by executing the exact pinned upstream action entry point with its production lockfile, `INPUT_FAIL_ON_ERROR=true`, and core `2.3.0`. It runs the official PHP streak CLI and Deno trophy CLI similarly. Every card is content-validated before a single publication commit; a generation error leaves the previous committed output intact. Local full-pipeline execution was verified with Node 24, PHP 8.3 and Deno 2.5.6. The streak upstream composer lock warns that its manifest has changed; locked production dependencies nevertheless install and generation succeeds.

Retained, unused decorative assets remain for reversible prior section removals. They are not shown in the current README.
